# City of Gainesville Team 3
Team 3 Digital Access Datasets
- - - 
All of the following files need to be saved to a Google Drive folder with name "capstone". Alternatively, these files can be saved to a Google Drive folder with another name, but the .ipynb file will need to change all instances of "capstone" to the new folder name. There is a code chunk at the top of the .ipynb file that will import all these files from the Drive folder to the code and will not run if this step is not completed.
